# FlowSiteAI - FlowSite AI Agency Website

Marketing website for **FlowSite AI**, a web development and AI automation agency.

## Page sections

Announcement banner, navigation, hero, presets, value proposition, how it works, use cases, client websites, core features, presets gallery, testimonials, pricing, FAQ, contact and footer.

## Tech stack

- Vite + React 18
- Tailwind CSS 3
- react-icons
- Vercel Analytics

## Project structure

```
src/components/layout/     Banner, navbar, footer
src/components/sections/   One component per page section
src/components/ui/         Shared UI pieces
src/data/                  Site content
src/hooks/                 Shared hooks
```

## Getting started

```bash
npm install
npm run dev       # development server
npm run build     # production build
npm run preview   # preview the build
```
